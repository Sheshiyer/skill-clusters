# Variable Contract Capacity

Skill-clusters preserves Cambium's richer handoff contract instead of flattening work into prose-only briefs.

## Taste

`taste/scripts/taste-resolve.mjs --json` emits the five groups Cambium declares for the taste stage:

- `taste_brief`
- `asset_plan`
- `section_plan`
- `interaction_plan`
- `acceptance_checks`

These fields are generated by `taste/scripts/lib/variable-contract.mjs`, so the shape is pure and testable without a NIM call.

## Build Routing

`scripts/resolve-task.mjs --json` attaches a `contract` object to each dispatch item:

- `scope`
- `section_type`
- `brand_archetype`
- `asset_requirements`
- `copy_slots`

The resolver still chooses the real cluster/orchestrator as before; the contract object rides beside that decision so downstream agents can keep section, asset, and copy intent attached to the task.

## Ship Gate

`scripts/ship-battery.mjs --contract <file>` validates a Cambium variable-contract pack before shipping. It fails closed when required groups are missing or empty:

- `brand_system`
- `copy_system`
- `visual_system`
- `asset_plan`
- `section_plan`
- `interaction_plan`
- `acceptance_checks`
