7 Short vs long — same spine

Short (days · pitch · landing)

Compress depth, keep order. One wave. Brand lite → one composition → static deploy → README + basic SEO.

Long (weeks · product)

Full phase→wave→swarm. Asset factory. Parallel OmniRoute workers. Continuous SEO/QA waves. Close with loop-feedback.

8 Operator recipe

  1. Write brief + constraints (stage 0).
  2. Lock brand via design-core / brandmint / refero (stage 1).
  3. Choose one of motionskin · scroll-world · custom (stage 2).
  4. Get budget go → generate assets with receipts (stage 4; motion as needed).
  5. Build frontend to taste + web-perf budget (stage 5).
  6. If multi-track: swarm waves with frozen contracts (stage 6).
  7. readme · SEO · PWA-if-app · ship-battery · deploy (stages 7–8).
